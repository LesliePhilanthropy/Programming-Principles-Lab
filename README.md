## Repository Structure and Projects

### Automated Calculators and Business Logic
*   **Vacation Calculator / Meal Cost Calculator:** Modular applications that parse data inputs to calculate tiered pricing and automated compliance additions (such as fixed percentage gratuities). Demonstrates functional isolation and multi-variable parameter mapping.
*   **Flooring Cost Calculator / Parking Cost Calculator:** Financial evaluation scripts utilizing operational boundary definitions to process variable metric equations.
*   **Income Tax Calculator / Sales Bonus Calculator:** Automated rule-mapping programs that process numeric values through strict, multi-tiered conditional logic bands.

### Data Administration and Identity Security
*   **Employee Data Program:** A utility program designed to store, manage, and retrieve structured staff records. Simulates the basic operational logic of data classification and access management systems.
*   **Bank Balance and Interest Calculator:** Financial tracking script focused on mathematical precision, transactional logic loops, and variable updates over simulated timelines.

### Algorithmic Logic and Optimization
*   **Combine Arrays and Remove Duplicates:** A data auditing script focused on array manipulation and sanitation. It identifies matching records across distinct data sets and programmatically enforces deduplication to ensure data optimization.
*   **Prime Numbers:** An algorithmic execution script focusing on computational math efficiency, mathematical constraints, and nested loop iterations.
