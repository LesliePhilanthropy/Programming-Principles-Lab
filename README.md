# Python Programming Projects

A structured collection of modular Python applications, interactive scripts, and utility programs developed during my Information Technology coursework at Kennesaw State University. 

These projects focus on applying core programmatic logic to enforce data integrity, handle secure data validation, and implement system logging and troubleshooting principles.

---

##  Core Technical Competencies Demonstrated

*   **Logical Architecture:** Designing modular systems using nested loops, conditional logic blocks, and data structures (lists, dictionaries, tuples).
*   **Functional Abstraction:** Writing clean, reusable functions with proper parameter passing, scoping, and abstraction layers.
*   **Data Integrity & Validation:** Engineering robust defensive programming mechanisms to sanitize user inputs, manage edge cases, and eliminate execution faults.
*   **Defensive Debugging & Logging:** Applying automated logging workflows, exception handling (`try-except`), and programmatic troubleshooting steps.
